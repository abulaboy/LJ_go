# 任務：第 82 版「⚾ 球場玩什麼？」活動總覽與快速前往面板

背景：北海道棒球場（ROOMS 裡 id 'escon'，範圍約 x:-170～170、z:630～970，roomAt(x,z).venue==='escon'）有很多互動：全壘打大賽、外野接球、內野守備、投手丘三振、看台應援、球員見面會、農業溫室、方塊島、TOWER 11、美食、商店、導覽……玩家常常找不到。

要做的事：
1. 只有玩家在北海道棒球場時，畫面左上「❓」按鈕右邊（🧰 按鈕約在 left:50px top:8px，請放 left:96px top:8px，44x44 圓角按鈕，emoji「⚾」）顯示按鈕；離開球場就隱藏。手機版同位置。快捷鍵 B（只在球場、焦點不在輸入框時）。
2. 按下開啟置中面板（寬 min(420px, 100% - 24px)，最高 80vh 可捲動），標題「⚾ 球場玩什麼？」。
3. 每次打開掃描 things，挑出 roomAt(t.x,t.z).venue==='escon' 的項目（try/catch 呼叫 label，空字串跳過，去掉結尾「（E）」），分類：
   - ⚾ 棒球挑戰：含 全壘打、接球、守備、投球、跑壘、三振、打擊
   - 📣 應援與表演：含 應援、吉祥物、北北熊、煙火、氣球、跳舞
   - 📸 拍照與簽名：含 拍照、合照、簽名
   - 🍜 美食與購物：含 吃、喝、買、商店、美食、點心、廚師、扭蛋、咖哩、拉麵、冰淇淋
   - 🌱 F VILLAGE 與戶外：x>60 或 z>860
   - ✨ 更多好玩的：其他（最多 40 個）
   同 label 只列一次（取最近的）。每項按鈕顯示 label 與「約 N 公尺」。分類可收合，預設只展開第一類。
4. 點項目：關閉面板，tpTo 到項目旁 1.2 公尺（朝向項目），say('到了！按「互動」就可以開始：' + label)。
5. 「關閉（B）」按鈕；Esc 也能關。
6. window.__moreTick2 串接，每 0.5 秒判斷一次是否在球場。
